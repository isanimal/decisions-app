Secure Coding Mitigation Knowledge Base (v1)
Decision-centric, context-aware, and human-first.

Tujuan
Knowledge Base ini membantu developer, AppSec, dan tech lead memilih mitigasi secara sadar berdasarkan keputusan nyata yang mereka ambil—bukan sekadar mengikuti checklist atau dogma.

Apa ini

Kumpulan Mitigation Cards berbasis decision pattern

Tiap card menyediakan opsi mitigasi bertingkat (minimal → standard → mature)

Menjelaskan trade-off (effort, complexity, performance, UX)

Terhubung ke hasil Decision App dan Threat Modeling Lite

Apa ini bukan

Bukan vulnerability scanner

Bukan checklist kepatuhan

Bukan database CVE

Bukan pengganti penilaian profesional

Cara Menggunakan

Buat keputusan di Decision App

Jalankan Threat Modeling Lite untuk mengekstrak asumsi, boundary, dan threat

Gunakan KB untuk:

menemukan MitigationCard yang relevan

memilih tier mitigasi sesuai konteks

mendokumentasikan alasan (decision record)

Struktur Card (ringkas)

Decision pattern → Risk → Mitigation tiers → Trade-offs → Verification ideas

Referensi (ASVS/SAMM/WSTG) hanya sebagai rujukan belajar, bukan kewajiban

Prinsip Kontribusi

Decision-first (bukan vulnerability-first)

Realistic threat (bukan ekstrem)

Selalu sertakan trade-off

Selalu ada opsi minimal

Tool/vendor-agnostic

Governance

v1: curated (seeded)

v1.1+: community PR dengan review ringan

Semua perubahan harus menjaga konsistensi taxonomy
